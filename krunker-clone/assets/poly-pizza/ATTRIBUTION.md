# Poly Pizza assets used / planned

The arena's container concept is based on the free Poly Pizza shipping-container asset:
- Container — KolosStudios
- Source: https://poly.pizza/m/CQMziXZfYh
- License: Creative Commons Attribution (verify the exact current license on the source page before redistribution)

This build keeps the game lightweight. The current browser build uses optimized low-poly container geometry in code rather than bundling a large binary model. The source attribution is retained so the asset can be swapped in locally later without changing the map layout.
