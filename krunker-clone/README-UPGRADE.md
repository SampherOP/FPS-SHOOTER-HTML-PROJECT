# LONEWOLF FPS Upgrade

Existing game preserved and upgraded with:
- 5-round match flow and round title sound
- Desert Eagle replacing USP
- Crouch (C), hold CTRL to slide with crouched height
- Sprint (SHIFT) with FOV, camera bob and weapon sway
- Weapon sway/recoil while walking, sprinting and aiming
- Muzzle flash + visible bullet tracers
- Headshots are lethal; bodyshots use normal damage
- Per-weapon stats and reload timings
- Per-weapon procedural firing/reload audio using Web Audio
- Red/blue shipping-container arena cover
- Crates, walls and additional low-poly cover
- Existing shop, AI, HUD, build mode, pause and menu retained

Run by opening index.html from a local web server (recommended) so browser security does not interfere with future local assets.
